# 📮 밴드 자동 글쓰기

매일 아침 **네이버 밴드에 글을 자동으로 올려 주는** 프로그램이에요.
네이버가 공식으로 제공하는 **밴드 Open API**를 사용하므로 매크로처럼 계정이 정지될 걱정이 없어요.
내 컴퓨터를 켜 둘 필요도 없어요. GitHub가 매일 대신 실행해 줘요.

---

## 어떻게 동작하나요?

- 매일 **한국 시간 오전 8시 50분쯤** 실행돼요.
- `글` 폴더에서 오늘 올릴 글을 골라요.
  1. 오늘 날짜 파일이 있으면 그 글을 올려요. 예: `2026-10-10.txt` (특별한 날용)
  2. 날짜 파일이 없으면 오늘 요일 파일을 올려요. 예: `월요일.txt`
  3. 파일이 **비어 있으면 그날은 올리지 않아요.**
- 글의 **첫 줄에 `[알림]`** 이라고 쓰면 회원들 휴대폰에 푸시 알림도 가요.
  (매일 알림을 보내면 회원들이 밴드 알림을 꺼 버릴 수 있으니 중요한 글에만 쓰세요.)

처음에는 예시로 `월요일`, `수요일`, `금요일` 글이 들어 있고 나머지 요일은 비어 있어요.

---

## 처음 한 번만 하는 설정 (약 10분)

### 1단계. 밴드 개발자 사이트에 앱 등록하기
1. 컴퓨터에서 https://developers.band.us 에 들어가요.
2. 오른쪽 위 **로그인**을 눌러 밴드장 계정으로 로그인해요.
3. 위쪽 메뉴의 **내 서비스**(또는 **Register Service**)를 눌러요.
4. 서비스 이름(예: `우리밴드 자동글`)을 적고 등록해요.
   - 주소(Redirect URI)를 물어보면 `https://github.com` 을 적어도 괜찮아요.

### 2단계. Access Token(출입증) 받기
1. 등록한 서비스 화면에서 **내 Access Token 확인**(또는 **Access Token 발급**)을 눌러요.
2. 밴드 연결을 허락하는 화면이 나오면 **동의**를 눌러요.
3. 길게 생긴 글자(예: `ZQAAA...`)가 나와요. 이게 **Access Token**이에요. 복사해 두세요.

> ⚠️ Access Token은 **내 밴드 계정 열쇠**예요. 카톡이나 게시글 등 다른 곳에 절대 붙여 넣지 마세요.

### 3단계. GitHub에 출입증 넣기 (비밀 금고)
1. 이 저장소 GitHub 페이지 위쪽에서 **Settings**를 눌러요.
2. 왼쪽 메뉴에서 **Secrets and variables** → **Actions**를 눌러요.
3. 초록색 **New repository secret** 버튼을 눌러요.
4. 이렇게 입력하고 **Add secret**을 눌러요.
   - Name: `BAND_ACCESS_TOKEN`
   - Secret: 2단계에서 복사한 Access Token

### 4단계. 내 밴드 번호(band_key) 알아내기
1. 저장소 위쪽에서 **Actions**를 눌러요.
2. 왼쪽 목록에서 **밴드 자동 글쓰기**를 눌러요.
3. 오른쪽의 **Run workflow** 버튼을 누르고, **내 밴드 목록 보기**를 고른 뒤 초록색 **Run workflow**를 눌러요.
4. 잠시 뒤 생긴 실행 기록 → **post** → **밴드에 글 올리기**를 누르면 이렇게 보여요.
   ```
   뽐뿌스마트폰 ...  (회원 14922명)  band_key: AAAbCdEf...
   ```
5. 글을 올릴 밴드의 `band_key` 값을 복사해요.
6. 3단계와 같은 방법으로 비밀을 하나 더 만들어요.
   - Name: `BAND_KEY`
   - Secret: 방금 복사한 band_key

### 5단계. 연습해 보기
1. **Actions** → **밴드 자동 글쓰기** → **Run workflow**에서 **연습 (올리지 않고 보기만)**을 골라 실행해요.
2. 기록을 열어 보면 오늘 어떤 글이 올라갈지 보여요. 밴드에는 올라가지 않아요.
3. 진짜로 올려 보고 싶으면 **지금 바로 올리기**를 골라요.

이제 끝! 다음 날부터는 매일 아침 자동으로 올라가요. 🎉

## 글 바꾸는 방법 (휴대폰으로도 가능)
1. GitHub에서 `band-bot/글` 폴더로 들어가요.
2. 바꾸고 싶은 요일 파일(예: `월요일.txt`)을 눌러요.
3. 연필 모양(✏️ Edit) 버튼을 눌러 내용을 고쳐요.
4. 초록색 **Commit changes** 버튼을 누르면 저장돼요.

**특정 날짜에만 다른 글을 올리고 싶을 때**
- `글` 폴더에서 **Add file** → **Create new file**을 눌러요.
- 파일 이름을 `2026-10-10.txt` 처럼 날짜로 적고 내용을 써서 저장해요.
- 그날은 요일 글 대신 이 글이 올라가요.

## 시간 바꾸는 방법
`.github/workflows/band-post.yml` 파일의 `cron: '50 23 * * *'` 부분을 고쳐요.
**한국 시간에서 9시간을 뺀** 시각을 `분 시` 순서로 적어요.

| 원하는 한국 시간 | 적을 값 |
|---|---|
| 오전 7시 | `'0 22 * * *'` |
| 오전 8시 50분 | `'50 23 * * *'` |
| 낮 12시 | `'0 3 * * *'` |
| 저녁 7시 | `'0 10 * * *'` |

## 잘 안 될 때
- **Actions에 "밴드 자동 글쓰기"가 안 보여요** → 이 파일들이 `main` 브랜치에 들어가 있어야 해요.
- **"BAND_ACCESS_TOKEN 이 비어 있어요"** → 3단계의 Name 철자를 다시 확인해요.
- **"밴드가 오류를 알려왔어요"** → Access Token이 만료됐을 수 있어요. 2단계에서 다시 받아 3단계 비밀을 바꿔 주세요.
- **60일 동안 저장소에 변화가 없으면** GitHub가 자동 실행을 멈출 수 있어요. 가끔 글을 고쳐 저장하면 계속 실행돼요.
