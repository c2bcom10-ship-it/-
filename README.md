# 🚂 Word Train (워드 트레인)

초등학교 1~6학년용 영어 끝말잇기 게임이에요.

- 기획서: [`docs/기획서.md`](docs/기획서.md)
- 출시 가이드: [`docs/출시가이드.md`](docs/출시가이드.md)
- 개인정보처리방침 초안: [`docs/개인정보처리방침.md`](docs/개인정보처리방침.md)
- 게임: [`game/index.html`](game/index.html)
  - 1단계: 학년 선택, 로봇 대결, 아이템 3종, 발음 듣기
  - 2단계: 코인·보석, 펫 키우기, 스티커북, 배지, 오늘의 도전, 출석 보상, 상점
  - 3단계: 친구랑 대결(휴대폰 하나로 번갈아), 대결 아이템 🪃🌪️, 모험 지도(6개 섬 × 3단계), 부모님 페이지(공부 기록·하루 게임 시간)
  - 4단계: 선생님 모드(우리 반 단어장 + 코드 공유), 2~4모둠 교실 대결, 🎤 말로 답하기, 앱처럼 설치(PWA)

## 게임 해보는 방법
1. `game/index.html` 파일을 내려받아요.
2. 파일을 두 번 클릭하면 브라우저(크롬 등)에서 바로 열려요. 설치할 것은 없어요.

## 단어 추가하는 방법
`game/index.html`을 메모장으로 열고 `const RAW = {` 부분을 찾아요.
학년 숫자 아래에 한 줄씩 `영어단어|뜻|그림` 형식으로 쓰면 돼요.

```
tiger|호랑이|🐯
```

## 기록은 어디에 저장되나요?
코인, 펫, 스티커 같은 기록은 **지금 쓰는 브라우저 안에만** 저장돼요.
다른 기기나 다른 브라우저에서 열면 처음부터 시작해요.

## 부모님·선생님 페이지
첫 화면 오른쪽 위 ⚙️ 버튼을 누르고 간단한 덧셈 문제를 풀면 들어갈 수 있어요.
선생님은 여기서 **우리 반 단어장**을 만들고, 나온 코드를 아이들에게 보내면 돼요.

## 웹사이트로 올리기
[`docs/출시가이드.md`](docs/출시가이드.md)의 1단계를 따라 하면 무료 웹사이트 주소가 생겨요.
