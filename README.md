# 🚂 Word Train (워드 트레인)

초등학교 1~6학년용 영어 끝말잇기 게임이에요.

- 기획서: [`docs/기획서.md`](docs/기획서.md)
- 게임: [`game/index.html`](game/index.html)
  - 1단계: 학년 선택, 로봇 대결, 아이템 3종, 발음 듣기
  - 2단계: 코인·보석, 펫 키우기, 스티커북, 배지, 오늘의 도전, 출석 보상, 상점

## 게임 해보는 방법
1. `game/index.html` 파일을 내려받아요.
2. 파일을 두 번 클릭하면 브라우저(크롬 등)에서 바로 열려요. 설치할 것은 없어요.

## 단어 추가하는 방법
`game/index.html`을 메모장으로 열고 `const RAW = {` 부분을 찾아요.
학년 숫자 아래에 한 줄씩 `영어단어|뜻|그림` 형식으로 쓰면 돼요.

```
tiger|호랑이|🐯
```

## 기록은 어디에 저장되나요?
코인, 펫, 스티커 같은 기록은 **지금 쓰는 브라우저 안에만** 저장돼요.
다른 기기나 다른 브라우저에서 열면 처음부터 시작해요.
