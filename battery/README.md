# 🔋 배터리 지킴이 (안드로이드 앱)

배터리가 줄어들면 **화면 밝기**와 **화면 꺼짐 시간**을 자동으로 줄여서 배터리를 아껴 주는 앱이에요.
충전기를 꽂으면 원래 설정으로 알아서 돌아가요.

| 배터리 | 단계 | 화면 밝기 | 화면 꺼짐 |
|---|---|---|---|
| 기준(기본 30%)보다 많을 때 | 평소 | 원래대로 | 원래대로 |
| 기준 이하 | 절전 | 약 30% | 30초 |
| 15% 이하 | 강력 절전 | 약 10% | 15초 |
| 충전 중 | 평소 | 원래대로 | 원래대로 |

기준 %는 앱 안의 막대로 20~50% 사이에서 바꿀 수 있어요.

## 꼭 알아 두세요
- **안드로이드 폰 전용**이에요. 아이폰은 앱이 다른 설정을 바꾸는 걸 애플이 막아 두어서 만들 수 없어요.
- 폰의 "절전 모드" 스위치 자체는 앱이 켤 수 없어요(구글이 막아 둠). 그래서 앱에 **폰의 절전 모드 설정 열기** 버튼을 넣어 두었어요.
- 와이파이·블루투스 끄기도 최근 안드로이드에서는 앱이 마음대로 못 해요.

## 앱 설치하는 방법 (컴퓨터 지식 없어도 돼요)
1. GitHub 저장소 위쪽의 **Actions** 탭을 눌러요.
2. 왼쪽에서 **Build Battery Keeper app**을 누르고, 맨 위의 초록색 ✅ 줄을 눌러요.
3. 화면 맨 아래 **Artifacts**에서 `battery-keeper-apk`를 눌러 내려받아요. (zip 파일이에요)
4. zip을 풀면 `app-debug.apk`가 나와요. 이 파일을 폰으로 옮겨요. (카카오톡 나에게 보내기, 구글 드라이브 등)
5. 폰에서 apk 파일을 눌러요. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켜고 설치해요.

## 앱 처음 쓰는 방법
1. 앱을 열고 알림 권한을 **허용**해요.
2. **화면 설정 권한 주기** 버튼 → "시스템 설정 변경 허용"을 켜고 뒤로 가기.
3. **자동 절전 켜기** 스위치를 켜요. 알림창에 "🔋 85% · 평소 모드"처럼 보이면 성공이에요.
4. 폰을 껐다 켜도 자동으로 다시 시작해요.

> 삼성 폰은 가끔 앱을 잠재워요. 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 "배터리 지킴이"를 넣어 주세요.

## 코드가 어디 있나요?
| 파일 | 하는 일 |
|---|---|
| `app/src/main/java/.../SaverRules.kt` | 몇 %에서 어떤 단계로 갈지, 밝기·시간을 얼마로 할지 (숫자를 바꾸고 싶으면 여기!) |
| `.../SaverService.kt` | 뒤에서 배터리를 지켜보다가 단계를 바꿔요 |
| `.../ScreenSettings.kt` | 실제로 밝기·꺼짐 시간을 바꾸고, 원래 값을 기억했다 되돌려요 |
| `.../MainActivity.kt` + `res/layout/activity_main.xml` | 앱 화면 |
| `.../BootReceiver.kt` | 폰을 켜면 자동으로 다시 시작 |
