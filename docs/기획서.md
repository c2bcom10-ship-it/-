# 🚂 워드 트레인 (Word Train) — 초등 영어 끝말잇기 앱 기획서

> 초등학교 1~6학년이 **학년에 맞는 영어 단어**로 끝말잇기를 하면서
> 놀이처럼 단어를 익히는 앱

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 앱 이름(가칭) | **워드 트레인 (Word Train)** — 단어 하나가 기차 한 칸! 이어질수록 기차가 길어져요 |
| 대상 | 초등 1~6학년 (7~13세) |
| 핵심 재미 | 기차 칸 늘리기 + 아이템 대결 + 캐릭터·스티커 수집 |
| 학습 목표 | 학년별 필수 영어 단어의 **철자·뜻·발음** 익히기 |
| 플랫폼 | 1단계: 웹앱(휴대폰·태블릿·PC 브라우저) → 2단계: 앱스토어 출시 |

## 2. 기본 규칙 (영어 끝말잇기)

앞 단어의 **마지막 알파벳**으로 시작하는 단어를 말해요.

```
apple → egg → goat → tiger → rabbit → ...
    e      g      t       r
```

### 공통 규칙
1. 한 판에서 **이미 나온 단어는 다시 쓸 수 없어요.**
2. 제한 시간 안에 답하지 못하면 **하트 1개**가 줄어요. (하트 3개)
3. 학년 단어장에 있는 단어 = 기본 점수, 단어장 밖의 진짜 영어 단어 = **보너스 점수**
4. 틀린 철자는 실패가 아니라 "앗! 다시 해볼까?" 로 1번 더 기회를 줘요. (아이들 좌절 방지)

### 어려운 끝 글자 보정 규칙 (중요!)
`x`, `z`, `q`, `j` 로 시작하는 쉬운 단어는 거의 없어서 아이들이 금방 막혀요.
- **저학년(1~2학년):** 이런 글자로 끝나면 자동으로 **끝에서 두 번째 글자**를 써도 돼요. (box → **o** → orange)
- **중학년(3~4학년):** 버튼을 눌러 선택할 수 있어요.
- **고학년(5~6학년):** 원래 규칙 그대로! 대신 "알파벳 바꾸기" 아이템으로 탈출할 수 있어요.

## 3. 학년별 난이도 설계

> 참고: 초등 영어 정규 수업은 3학년부터 시작하고, 교육부 교육과정의 초등 권장 어휘는 약 **500~800개** 수준이에요.
> 1~2학년은 파닉스(알파벳 소리) 수준의 아주 쉬운 단어 위주로 구성해요.

| 학년 | 단계 이름 | 단어 길이 | 단어장 크기 | 제한 시간 | 도움 기능 | 단어 예시 |
|---|---|---|---|---|---|---|
| 1학년 | 🥚 알 단계 | 3글자 | 약 100개 | 30초 | 그림 보기 + **알파벳 버튼으로 입력** + 첫 글자 힌트 항상 표시 | cat, dog, sun, egg, pig |
| 2학년 | 🐣 병아리 단계 | 3~4글자 | 약 200개 | 25초 | 그림 보기 + 알파벳 버튼 | bear, milk, fish, book |
| 3학년 | 🐥 아기새 단계 | 3~5글자 | 약 350개 | 20초 | 그림 힌트 (아이템 사용) | apple, tiger, water, lemon |
| 4학년 | 🐦 파랑새 단계 | 4~6글자 | 약 500개 | 20초 | 뜻 힌트 (아이템 사용) | orange, rabbit, school, pencil |
| 5학년 | 🦅 독수리 단계 | 4~7글자 | 약 650개 | 15초 | 힌트 최소화 | weather, holiday, library |
| 6학년 | 🐉 드래곤 단계 | 5글자 이상 | 약 800개 | 15초 | 힌트 없음, 긴 단어 보너스 | adventure, festival, elephant |

### 학년별 단어 주제 (테마)
- **1~2학년:** 동물, 과일, 색깔, 숫자, 가족, 몸
- **3~4학년:** 학교, 음식, 날씨, 동작(run, jump), 장소
- **5~6학년:** 직업, 교통, 감정, 계절·행사, 자연, 스포츠

> 💡 학년은 처음에 고르지만, 잘하면 "한 단계 위 도전!", 어려워하면 "한 단계 쉬운 모드"를 **자동으로 추천**해 줘요.

## 5. 🎁 아이템 (아이들이 좋아할 핵심 요소)

### 5-1. 게임 중에 쓰는 아이템

| 아이템 | 이름 | 효과 | 얻는 방법 |
|---|---|---|---|
| 💡 | **반짝 전구** | 정답 단어의 첫 두 글자를 보여줘요 | 기본 지급 / 코인 |
| 🖼️ | **그림 카드** | 쓸 수 있는 단어의 그림을 보여줘요 | 코인 |
| 🧊 | **얼음 시계** | 제한 시간을 10초 멈춰요 | 코인 |
| 🔄 | **알파벳 바꾸기** | 어려운 끝 글자를 다른 글자로 바꿔요 (x → e) | 미션 보상 |
| 🛡️ | **튼튼 방패** | 한 번 틀려도 하트가 안 줄어요 | 코인 |
| ✨ | **더블 스타** | 다음 단어 점수 2배 | 연속 정답 보너스 |
| 🪃 | **부메랑** (대결 전용) | 상대에게 어려운 글자(예: k, v)로 끝나는 단어를 돌려줘요 | 대결 승리 보상 |
| 🌪️ | **회오리** (대결 전용) | 상대 화면 알파벳 버튼을 3초간 섞어요 | 대결 승리 보상 |
| 🍀 | **네잎클로버** | 하트 1개 회복 | 오늘의 도전 보상 |

> ⚖️ 아이템은 **한 판에 최대 3개**까지만 쓸 수 있어요. (실력보다 아이템이 중요해지는 것 방지)

### 5-2. 수집·꾸미기 아이템 (계속 하고 싶게 만드는 요소)

- 🐾 **단어 펫 키우기**
  - 알에서 시작 → 단어를 맞힐수록 먹이(🍎)를 먹고 성장 → 진화!
  - 학년 단계 이름(알 → 병아리 → … → 드래곤)과 연결돼요.
- 🚃 **기차 꾸미기**
  - 기차 색깔, 굴뚝 연기 모양(하트·별·무지개), 기차 칸 무늬 바꾸기
- 📒 **단어 스티커북**
  - 새 단어를 처음 맞히면 그 단어의 **그림 스티커**를 얻어요.
  - 주제별 페이지(동물, 과일…)를 다 채우면 **황금 스티커** 획득!
- 🏅 **배지 (업적)**
  - "첫 10칸 기차", "동물 박사", "7일 연속 출석", "X로 시작하는 단어 성공!" 등
- 👑 **칭호**
  - 이름 옆에 붙는 칭호: "과일 요정", "스펠링 마법사", "끝말잇기 왕"

### 5-3. 재화 (코인)

| 재화 | 얻는 방법 | 쓰는 곳 |
|---|---|---|
| 🪙 **별 코인** | 게임 플레이, 정답, 출석 | 아이템, 꾸미기 |
| 💎 **무지개 보석** | 스티커 페이지 완성, 배지 획득 | 특별 펫, 희귀 꾸미기 |

> 🚫 **현금 결제(유료 아이템)는 넣지 않는 것을 추천해요.** 어린이 앱은 부모님 신뢰가 가장 중요하고, 앱스토어 심사도 까다로워요.

## 6. 학습 기능 (공부가 되는 부분)

1. 🔊 **발음 듣기** — 단어를 입력하면 원어민 발음으로 읽어줘요. (브라우저 음성 기능 사용)
2. 🖼️ **그림 + 뜻** — 맞힌 단어는 그림과 한국어 뜻을 잠깐 보여줘요.
3. 📝 **나만의 단어장** — 한 판에서 나온 단어가 자동 저장돼요.
4. ❌ **다시 보기 노트** — 틀리거나 못 떠올린 단어를 모아서 복습 퀴즈로 내줘요.
5. 🎤 **말로 답하기** (2단계) — 마이크로 단어를 말하면 인식해요. 저학년이 타자 대신 쓸 수 있어요.

```
[1] 시작 화면

  └───────────────────────────┘
          ↓

  ┌───────────────────────────┐

  │ [🤖 로봇 대결] [🚂 혼자하기] │
```

### 디자인 방향
- 밝고 둥근 파스텔 색, 큰 글씨, 큰 버튼 (손가락으로 누르기 쉽게)
- 정답 시: 기차 "칙칙폭폭!" 소리 + 칸이 붙는 애니메이션 + 폭죽
- 오답 시: 무섭지 않게 펫이 "괜찮아~" 하고 격려
- 1~2학년은 **글 대신 그림·소리 안내**를 많이 써요.

## 9. 안전 · 개인정보

- 이름 대신 **닉네임 + 캐릭터**만 사용 (실명, 사진, 위치 수집 X)

## 10. 만드는 방법 (기술 구성 — 초보자 추천 경로)

### 추천: 웹앱으로 시작하기
| 구분 | 사용 기술 | 이유 |
|---|---|---|
| 화면 | HTML + CSS + JavaScript | 따로 설치할 것 없이 브라우저만 있으면 돼요 |
| 발음 | 브라우저 내장 음성(Web Speech API) | 무료, 추가 설정 없음 |
| 저장 | 브라우저 저장소(localStorage) | 로그인 없이 기록 저장 |
| 단어 데이터 | JSON 파일 (학년별) | 엑셀처럼 단어를 쉽게 추가·수정 |
| 앱 설치 | PWA(홈 화면에 추가) | 휴대폰에서 앱처럼 실행 |

### 단어 데이터 예시 (`words/grade1.json`)
```json
[
  { "word": "cat",  "meaning": "고양이", "theme": "동물", "emoji": "🐱" },
  { "word": "egg",  "meaning": "달걀",   "theme": "음식", "emoji": "🥚" },
  { "word": "sun",  "meaning": "해",     "theme": "자연", "emoji": "☀️" }
]
```

### 로봇(컴퓨터)이 답하는 방법
1. 앞 단어의 마지막 글자를 확인해요.
2. 학년 단어장에서 그 글자로 시작하고, 아직 안 나온 단어를 찾아요.
3. 로봇 난이도에 따라:
   - 쉬움 😊: 가끔 일부러 못 찾아요 (아이가 이길 수 있게)
   - 보통 🙂: 무작위로 골라요
   - 어려움 😎: 아이가 받기 **어려운 글자로 끝나는 단어**를 골라요

## 12. 성공 기준 (잘 되고 있는지 확인하는 방법)

- 한 번 켜면 평균 **3판 이상** 하는가?
- 다음 날 다시 들어오는 아이가 **40% 이상**인가?
- 1주일에 새로 익힌 단어가 **20개 이상**인가?
- 아이들이 "한 판만 더!"라고 하는가? (가장 중요 😄)
