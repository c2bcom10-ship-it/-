# 📱 워드 트레인 출시 가이드 (초보자용)

게임을 아이들 휴대폰에 설치하기까지 **3단계**로 나눠서 설명해요.
앞 단계가 끝나야 다음 단계로 갈 수 있어요.

| 단계 | 결과 | 비용 | 난이도 |
|---|---|---|---|
| 1. 웹사이트 주소 만들기 | `https://아이디.github.io/-/` 같은 주소가 생겨요 | 무료 | ⭐ |
| 2. 휴대폰에 앱처럼 설치 | 홈 화면에 🚂 아이콘이 생겨요 | 무료 | ⭐ |
| 3. 앱스토어 출시 | 구글 플레이, 애플 앱스토어에서 검색돼요 | 유료 | ⭐⭐⭐ |

> 💡 **대부분은 1~2단계로 충분해요.** 반 아이들이나 가족이 쓰기에는 웹사이트 주소만 알려줘도 돼요.

---

## 1단계. 웹사이트 주소 만들기 (GitHub Pages, 무료)

저장소에 `.github/workflows/pages.yml` 파일을 이미 넣어 뒀어요.
이 파일이 게임 폴더(`game`)를 웹사이트로 올려 줘요.

### ① 저장소를 "공개(Public)"로 바꾸기
무료 계정에서는 **공개 저장소**만 GitHub Pages를 쓸 수 있어요.
1. GitHub에서 저장소(`c2bcom10-ship-it/-`)로 가요.
2. **Settings**(⚙️ 설정) 탭을 눌러요.
3. 맨 아래 **Danger Zone** → **Change visibility** → **Make public**을 눌러요.

> ⚠️ 공개로 바꾸면 누구나 코드를 볼 수 있어요. 게임 코드에는 비밀번호 같은 정보가 없어서 괜찮아요.

### ② Pages 켜기
1. **Settings** → 왼쪽 메뉴 **Pages**를 눌러요.
2. **Build and deployment** → **Source**를 **GitHub Actions**로 바꿔요.

### ③ 작업 브랜치를 main에 합치기
지금 게임은 `claude/korean-word-chain-app-design-s9mini` 브랜치에 있어요.
웹사이트는 **main 브랜치**에서만 만들어져요.
- Claude에게 **"PR 만들어줘"**라고 하면 합치기 요청(Pull Request)을 만들어 드려요.
- GitHub에서 그 PR을 열고 초록색 **Merge pull request** 버튼을 누르면 합쳐져요.

### ④ 주소 확인하기
1. 저장소의 **Actions** 탭에서 "Deploy game to GitHub Pages"에 초록 체크 ✅가 뜨길 기다려요 (1~2분).
2. **Settings** → **Pages** 맨 위에 주소가 나와요.
   예: `https://c2bcom10-ship-it.github.io/-/`

이 주소로 열면 **🎤 말로 답하기**도 쓸 수 있어요.

---

## 2단계. 휴대폰에 앱처럼 설치하기 (무료)

1단계에서 만든 주소를 휴대폰에서 열어요.

**안드로이드 (크롬)**
1. 오른쪽 위 **⋮** 메뉴를 눌러요.
2. **홈 화면에 추가** 또는 **앱 설치**를 눌러요.

**아이폰 (사파리)**
1. 아래쪽 **공유 버튼(□↑)**을 눌러요.
2. **홈 화면에 추가**를 눌러요.

이제 홈 화면의 🚂 아이콘을 누르면 앱처럼 전체 화면으로 열려요.
한 번 열고 나면 **인터넷이 끊겨도** 게임이 열려요. 단, 말로 답하기는 인터넷이 필요해요.

---

## 3단계. 앱스토어 출시 (유료, 선택)

### 공통 준비물
- [ ] 1단계 웹사이트 주소
- [ ] **개인정보처리방침 웹 주소**: `docs/개인정보처리방침.md` 초안을 다듬어서 웹에 올려요
- [ ] 앱 설명, 스크린샷 (휴대폰 화면 캡처 3~5장)
- [ ] 아이콘: `game/icon-512.png`

### 🤖 구글 플레이 (안드로이드)
| 항목 | 내용 |
|---|---|
| 비용 | 개발자 등록비 **25달러 (한 번만)** |
| 필요한 것 | 구글 계정, 신분 확인 |
| 걸리는 시간 | 등록 확인 며칠 + 앱 심사 며칠 |

1. [Google Play Console](https://play.google.com/console)에서 개발자 계정을 만들어요.
2. [PWABuilder](https://www.pwabuilder.com)에 1단계 주소를 넣으면 **안드로이드 앱 파일(.aab)**을 만들어 줘요.
3. Play Console에서 새 앱을 만들고 파일을 올려요.
4. **타깃층 및 콘텐츠**에서 "13세 미만 아동"을 고르면 **가족 정책(Families Policy)** 심사를 받아요.
   - 광고, 결제, 개인정보 수집이 없어서 통과하기 좋은 조건이에요.
5. 개인 개발자 계정이라면 출시 전에 **테스터 여러 명이 일정 기간 테스트**해야 할 수 있어요. Play Console 안내를 따라 주세요.

### 🍎 애플 앱스토어 (아이폰)
| 항목 | 내용 |
|---|---|
| 비용 | Apple Developer Program **매년 99달러** |
| 필요한 것 | **맥(Mac) 컴퓨터**와 Xcode 프로그램 |
| 걸리는 시간 | 심사 며칠 (거절되면 고쳐서 다시 내요) |

1. [Apple Developer](https://developer.apple.com/programs/)에 가입해요.
2. PWABuilder에서 **iOS 패키지**를 받아서 맥의 Xcode로 열어요.
3. App Store Connect에 올리고 **키즈 카테고리**를 골라요.
   - 키즈 카테고리는 외부 광고와 분석 도구를 넣으면 안 돼요. 워드 트레인은 둘 다 없어요.
4. ⚠️ 애플은 "웹사이트를 그대로 감싼 앱"을 거절할 때가 있어요. 거절되면 **애플 기능(예: 알림)을 추가**하는 작업이 필요할 수 있어요.
